## [IDEA-001] QQ群自动发送消息工具
- 时间: 2026-07-28
- 原始想法: 做一个能自动往 QQ 群里发消息的工具，省得手动复制粘贴。
- 想达成的目标: 在多个 QQ 群批量触达用户（用于推广 / 通知）。
- 领域/场景: 社群运营 / 私域触达 / 推广分发
- 结构化分析:
  - 本质: 社群批量触达 + 营销自动化。
  - 现成工具:
    - 机器人协议框架：NoneBot2（Python）、Koishi（JS）、LLOB、基于 OneBot 的 go-cqhttp / NapCat。
    - 官方合规通道：QQ 频道机器人（官方 API）、企业微信、微信群机器人 Webhook。
  - 大佬 / 行业做法: 矩阵小号 + 养号 + "先给价值再广告" + 控制频率 / 错峰；内容前置价值降低被踢率。
  - 痛点 / 缺口: 协议登录易被腾讯风控封号；协议稳定性随版本波动；群内硬广易被踢 / 被举报。
  - 建议自研: 用 NoneBot2 + 定时任务 + 消息模板库，封装成"群发调度器"；优先走官方频道机器人规避封号。
  - 优先级: 中（是分发渠道之一，但需配合内容与养号）

## [IDEA-002] 网盘推广
- 时间: 2026-07-28
- 原始想法: 想做网盘推广赚钱，但不知道该怎么入手、用什么工具。
- 想达成的目标: 通过推广百度网盘 / 夸克 / 天翼等网盘拉新赚佣金。
- 领域/场景: 联盟营销 / 拉新裂变 / 内容变现
- 结构化分析:
  - 本质: 联盟营销——用"资源 / 内容"吸引用户，通过你的专属链接转存 / 开通会员而转化。
  - 现成工具 / 平台:
    - 百度网盘会员推广联盟、夸克网盘"夸克合伙人"、天翼云盘推广等官方联盟。
    - 推广形态：分享资源链接 + 你的邀请码 / 渠道参数。
  - 大佬 / 行业做法:
    - 资源站 / 公众号 / 短视频"种草"，把干货资源存网盘，用户转存即可能转化；
    - 自动化：采集热门资源 → 转存到自己网盘 → 生成带渠道的推广链接 → 多平台分发；
    - 矩阵账号 + SEO 占位 + 社群裂变（群文件 + 群发）。
  - 痛点 / 缺口: 平台规则多变、佣金结算周期、转化率、内容合规、资源被和谐。
  - 建议自研: ① 推广链接管理器（带渠道参数、追踪转化）；② 资源采集 + 转存自动化（对接网盘 API）；③ 多平台分发调度（复用 IDEA-001 的群发）；④ 转化数据看板。
  - 优先级: 高（这是当前主线目标，其他工具都围着它转）
