你能用它干什么

1. 全量清单导出

把网盘里所有文件的名字、大小、位置拉成本地表。这是其他所有功能的"地基"，新增文件后跑一次就能更新。

quark.bat export
双击「一键导出清单.bat」即可

2. 视频索引

给 15 万+ 视频建索引：读字幕和简介文本，之后就能按"剧情/类型/演员"找视频，不用记住文件名。

quark.bat index
双击「一键视频索引.bat」即可

3. 画面识别

对指定视频抽帧 + AI 写画面描述和标签。字幕里没有的画面（雪山、赛博朋克、某演员）也能搜到。按文件夹分批做，会消耗视觉 API 额度。

quark.bat frames --folder "电影/2024" --sample 20
需 VLM_API_KEY（已设则免）

4. 语义检索

用大白话搜视频："找有雪山的电影""讲一个人失忆后找家人"。画面 + 字幕一起搜，双击进交互模式一条条问。

quark.bat search
双击「一键搜索视频.bat」即可（交互式）

5. 网盘去重

找出内容重复的文件（同一套资料复制了十几份那种），出报告估算能释放多少空间。已发现约 1.9TB。默认只出报告不动文件，复核后再执行。

quark.bat dedup
quark.bat dedup --confirm 50
先 --confirm 复核，再 --apply 才真删

6. 批量重命名

把网盘文件批量改名，比如把文件名里的"副本"两个字删掉。默认只出预览，确认后才真正改名。

quark.bat rename --find "副本" --replace ""
先看预览，加 --apply 才执行

7. 每周自动更新

注册后每周日 14:00 自动跑一次"导出清单 + 视频索引"，结果自动覆盖旧的。不想用了随时取消。

quark.bat setup
quark.bat remove
前提：电脑开着 + cookie 没过期
常用提醒
· 所有数据都在 D:\workbuddy\网盘工具\夸克网盘\：脚本、cookie、清单、索引、报告放一起，整理好不乱跑。
· cookie（登录态）放在同一目录的 quark_cookie.txt；过期了重新登录网盘复制一次即可。
· 去重执行动作默认"移入回收站/隔离夹"，可恢复；执行前会要求输入 YES 二次确认。
· 画面识别和搜索的 AI 相关功能需要视觉模型 API Key（VLM_API_KEY），已配置系统环境变量则免填。
