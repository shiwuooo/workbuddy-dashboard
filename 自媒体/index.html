方法论速查
埃德蒙《万能素材库搭建课》核心（2025 整理版）：
① 米缸比喻：素材库=家里的米，随时有米下锅，不临时找；
② 避免抄袭：抖音查得严，70% 好内容=“借鉴形式+改文案”，不是纯原创；
③ 6 个找素材法：搜关键词 / 盯行业大V / 收集客户常问 / 蹭热点 / 跨行业偷创意 / 垂直网站公众号；
④ 5 个抖音收藏夹：选题收藏、好的呈现、故事案例、文案金句、表现力参考。
做自媒体准备清单：定位人设 → 选题库(30 对标爆款) → 万能素材库(7 类) → 模块化写作 → 表现力 → 剪辑 → 差异化起号 → 拆片。
使用说明
• 万能素材库：数据自动保存在浏览器本地（localStorage）。换电脑/清缓存前，点工具内「导出JSON」备份到 D 盘；换设备后用「导入」恢复。
• 本地双击 index.html 可用；带 file:// 的卡片仅在本地双击时有效，在线版请用「万能素材库」等网页工具。
• 本面板与万能素材库已部署到 GitHub Pages，手机/任意设备访问上方「在线版」即可。
