# 💰 赚钱面板（零积分 · 本地软件版）

一个**完全不经过 WorkBuddy、不消耗任何积分**的本地资讯软件。
每天自动抓取国内外「副业 / 创业 / 行业动向 / 被动收入」信息，你在浏览器里自己点、自己看。
所有数据都在本地 `D:\workbuddy\赚钱面板\`。

## 四个标签页（一个面板里全搞定）
- **📡 资讯流**：每天抓取的 RSS 原始资讯，按国内/海外、分类筛选、搜索。
- **🤖 AI 每日解读**：WorkBuddy 帮你消化成小白能懂的中文简报（这份才耗积分，建议每周 1–2 次）。
- **📚 项目库**：现成的开源阅读器 / 知识库 / 自动化工具，点开即看。
- **ℹ️ 关于**：本说明。

## 零积分原理
- 采集由本机 `collector.py`（纯标准库）完成，抓公开 RSS，**无 API Key、无 AI 调用**。
- 自动更新由 Windows 计划任务触发，不经过 WorkBuddy，因此**不扣积分**。
- 真正的成本只有「电费 + 你电脑几分钟运行时间」。

## 最快用法：直接双击「赚钱面板-成品.html」（推荐）
- 文件路径：`D:\workbuddy\赚钱面板\赚钱面板-成品.html`
- **双击即用**，无需服务器、无需 `.bat`、不依赖任何外部文件。
- 所有内容（资讯 + AI 日报 + 项目库 + 说明）都已内联在页面里，可筛选/搜索/点击跳转。
- 这是「离线成品版」，数据更新需等待每天自动化生成新页面，或你自己运行采集器后重新生成。

## 完整动态版用法（适合想每天自动更新的人）
1. 双击 **`start.bat`** → 自动起本地服务器并打开 http://127.0.0.1:8000（所有功能正常）。
2. 首次数据为空时，双击 **`立即采集.bat`** 生成 `data.json` + 同步 AI 解读；或双击 **`register_task.bat`** 注册「每天 09:00 自动跑」，之后免管。
3. 面板里点标签页、筛选、搜索即可。

> ⚠️ 不要直接双击 `index.html`（file:// 方式）打开——浏览器会拦截本地文件读取，AI 解读/资讯会加载不出来。请用 `start.bat` 或直接用「赚钱面板-成品.html」。

## 双击 `.bat` 被 Windows 安全中心拦截怎么办？
这是 Windows 对“来自 Internet 的文件”的默认保护。解决方法：
1. 在资源管理器里右键 `.bat` 文件 → **属性**。
2. 在“常规”选项卡底部勾选 **“解除锁定”** → 确定。
3. 再次双击即可正常运行。

如果希望完全避免这个问题，**直接用「赚钱面板-成品.html」即可**，它不需要任何 .bat。

## 想加自己的源？
编辑 `feeds.json`：
- 普通 RSS：加 `{ "name":"名字", "url":"RSS地址", "region":"国内/海外", "category":"分类", "limit":10 }`
- 走 RSSHub 的站点：加 `{ "name":"名字", "rsshub":true, "route":"/路由路径", "region":"国内", "category":"副业" }`
  - 路由见 RSSHub 文档（如 `/zhihu/search/副业`、`/weibo/keyword/副业赚钱`）
改完双击「立即采集.bat」即可生效。

## 信息源说明
- **海外源**（Hacker News、Reddit r/SideHustle、Side Hustle Nation 等）为原生 RSS，**稳定、无需代理**。
- **国内源**通过 RSSHub 公益实例（`rsshub.app`）生成，可能偶尔不稳或限速。
  - 若打不开：把 `feeds.json` 里的 `rsshub_base` 改成其它公益实例，或直接用 **Folo**（项目库里有）。
  - 想更稳可自己 Docker 搭 RSSHub。

## ⚠️ 网络环境说明（重要）
- 采集依赖本机出网。某些环境（公司代理、沙箱、部分大陆网络）会**拦截对 Hacker News / Reddit / RSSHub 等站点的访问**，表现为「成功源 0 / 暂不可达 12」。
- 这是网络环境问题，**不是脚本 bug**。换到有完整外网的机器（或本机直连）双击 `立即采集.bat` 即可正常抓到数据。
- 已配套一个「赚钱面板-自动采集」自动化（id: `automation-1785598587886`）：在 WorkBuddy 的有外网运行时里自动跑采集并推飞书通知，无需你手动操作。若届时仍全失败，说明该运行时网络也被限，请在你本机双击 `立即采集.bat`。
