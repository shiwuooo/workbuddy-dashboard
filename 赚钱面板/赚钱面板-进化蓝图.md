## 1. 千万富翁视角：这个工具该是什么

普通人要的是「怎么赚第一笔 100 块」；千万富翁要的是**杠杆、先发优势、和高 ROI 机会**。

| 维度 | 普通人工具（v1.0） | 千万富翁工具（蓝图目标） |
|---|---|---|
| 关注点 | 副业点子、怎么起步 | 高回报机会、套利、资产配置、退出 |
| 时间观 | 追热点 | 抢**提前量**（趋势爆发前 3–12 个月） |
| 动作 | 看 + 记 | 看 + **自动执行** + 复盘放大 |
| 杠杆 | 自己时间 | 钱 + AI + 别人时间（自动化/外包） |
| 风险 | 怕被骗 | 系统级**风险哨兵**（政策/封号/骗局/合规） |
| 圈子 | 零散资讯 | **交易流（deal flow）**——早期项目、融资、并购信号 |

**一句话定位**：一个**赚钱情报指挥中枢**——左边喂全网信号，中间 AI 判分+给落地姿势，右边一键/自动执行，底下资产看板持续复盘。

## 2. 市面对标全景（国内外 + 开源，7 大类）

| 类别 | 海外代表（价格） | 国内代表（价格） | 开源/可白嫖 |
|---|---|---|---|
| **① 趋势雷达** | Exploding Topics($39+/mo)、Glimpse($99/mo)、Trends MCP($29/mo)、Google Trends(免费)、SparkToro($50/mo) | 百度指数(免费)、5118(¥)、新榜(¥) | RSSHub、NewsNow、FreshRSS |
| **② 选品/电商数据** | Jungle Scout、Helium 10 | **蝉妈妈(≈¥2万/年)**、飞瓜(≈¥8000/年起)、抖查查、考古加、抖创汇AI | — |
| **③ 内容自动化** | **MoneyPrinter V2**(开源)、OpusClip、HeyGen、Pictory、Midjourney、CapCut AI | 剪映、即梦、可灵 | MoneyPrinterTurbo、OpenClaw |
| **④ 执行/自动化** | **n8n**(自托管免费)、Make($9/mo)、Zapier($20/mo) | — | Huginn、Activepieces |
| **⑤ 创投/交易流** | Crunchbase($588/yr)、PitchBook($24k–40k/yr)、Harmonic($10k–30k/yr)、GitDealFlow(免费 MCP)、Tracxn | 36氪、IT桔子、鲸准 | — |
| **⑥ 圈子/知识** | Indie Hackers、Side Hustle Nation | **生财有术**、知识星球、小报童 | awesome-indie、chinese-independent-developer、howto-make-more-money、ai-money-maker-handbook |
| **⑦ 资产/复盘** | 个人记账/Notion 模板 | 飞书多维表、Notion | — |

**关键情报差（来自本次调研）**：
- **Trends MCP / GitDealFlow**：AI-native 趋势数据通过 MCP 直喂模型，模型能「实时查」而非「凭记忆猜」；GitDealFlow 用 GitHub commit 加速度作领先指标，比融资官宣**早 3–6 周**。
- **Crunchbase 向前看（预测融资/退出/风险），PitchBook 向后看（复盘历史交易）**——我们要的是「向前看」的提前量。
- **n8n MCP**：把工作流暴露成 AI 的「工具」，实现「AI 不只是聊天，而是直接在你的业务系统里行动」。
- **MoneyPrinter V2**：从「一个主题」到「成片」全流水线，本地优先（Ollama），零订阅。
- **蝉妈妈/飞瓜** 国内电商数据最深，但贵且**不开放公开 API**——只能抓公开榜单/评论区需求，不能走官方接口。

## 3. 融合后的「超级赚钱中枢」——8 大模块

每个模块：**参考谁 → 学什么 → 我们怎么做 → 零积分？ → 优先级**

### M1 趋势雷达（Trend Radar）
- **参考**：Exploding Topics（增长加速度评分）、Glimpse（绝对量）、Trends MCP（多源实时）、Google Trends（免费基线）
- **我们做**：聚合 RSS + agent-reach + WebSearch，给每条信号打「增速分 + 提前期 + 国内/海外差」，自动标 **「海外已火、国内没卷」** 的信息差红利
- **零积分**：采集零积分；评分全用规则，无需 AI
- **现状**：✅ 已交付（2026-08-12，多维规则打分，面板「🔥 趋势雷达」标签，每条资讯同步带分）
- **优先级**：P0（已完成）

### M2 选品/套利引擎（Product & Arbitrage）
- **参考**：蝉妈妈/飞瓜（爆品榜、增速、价格带、佣金、退货率）、抖查查（生命周期）、Jungle Scout（跨境）
- **我们做**：抓抖音/淘宝/拼多多**公开榜单 + 评论区需求**，AI 打分输出「可做/谨慎/不做」+ 理由；叠加**跨境套利**（国内货源 → 海外平台）提示
- **零积分**：抓公开页零积分；AI 判分耗积分（可每周 2 次）
- **优先级**：P1

### M3 内容工厂（Content Factory）
- **参考**：MoneyPrinter V2（脚本→配音→画面→字幕全流水线）、OpusClip（长转短）、HeyGen（数字人）、CapCut AI
- **我们做**：接入本地 LLM + TTS + 免费素材（Pexels），一键生成短视频/文章/社媒帖；M1/M2 发现的选题自动进工厂排队
- **零积分**：本地模型零积分；商用 API 才花钱
- **优先级**：P1（需本机有模型/API key）

### M4 自动化执行层（Execution Layer）
- **参考**：n8n（自托管免费、400+ 集成、MCP 暴露）、Huginn（规则监控）、Make/Zapier
- **我们做**：把「发现 → 执行」打通。例：监控到某品增速>200% → 自动生成 3 条带货脚本 → 定时发草稿。本地面板 + Python/n8n 调度
- **零积分**：n8n 自托管免费；仅 API 调用费
- **优先级**：P2（杠杆核心）

### M5 交易流/投资情报（Deal Flow）
- **参考**：Crunchbase（向前看预测）、Harmonic（信号源挖掘）、GitDealFlow（GitHub 加速度领先指标）、生财有术（国内实战精华）
- **我们做**：监控融资新闻 + GitHub 加速项目 + 生财有术精华，输出「早期机会清单 + 为什么现在」；对接想跟投/想抄模式的人
- **零积分**：采集零积分；AI 摘要耗积分（每周 2 次）
- **优先级**：P1（信息差最大）

### M6 资产/项目看板（Portfolio Board）
- **参考**：PitchBook（个人降级版）、飞书多维表
- **我们做**：本地记录「你在做的项目 / 收入 / ROI / 状态 / 下一步」，手动+自动（M3/M4 回写）；跨月看哪个赚钱、哪个该砍
- **零积分**：纯本地 Markdown/JSON / localStorage
- **现状**：✅ 已交付（2026-08-12，面板「📊 复盘看板」标签，记录投入/回报/ROI，可导出入备份）
- **优先级**：P0（已完成）

### M7 风险哨兵（Risk Sentinel）
- **参考**：各平台合规/诈骗识别、Crunchbase 风险预测
- **我们做**：规则+AI 标注「交押金/培训费=骗局」「政策敏感」「平台封号风险」「专利/侵权」；每条机会旁自动挂风险提示
- **零积分**：规则免费；AI 判分耗积分
- **优先级**：P0（**已于 2026-08-12 上线**，零积分，见面板资讯流/趋势雷达卡片的 🚫红线/⚠️警惕/📋留意 标签）

### M8 圈子/信息差（Circle & Asymmetry）
- **参考**：生财有术、知识星球、小报童、Indie Hackers、Side Hustle Nation
- **我们做**：RSS + agent-reach 抓精华帖/周报，去水存干；标记「仅圈子可见的早期信号」
- **零积分**：采集零积分
- **优先级**：P1

### M9 中外信息差 · 套利案例库（Cross-border Arbitrage）
- **参考**：用户直播观察（日本街头卖中国 90 年代卡通贴）+ 海外真实案例（大白兔糖纸走红海外、TikTok 中式锻打菜刀 11 倍溢价、眼线印章笔 20 倍溢价、草坪打孔器 5 倍溢价、世界杯国旗贴纸留学生赚 50 万）
- **我们做**：专门一条「中外信息差」流——把「国内过时=海外潮流」「供应链成本差→海外溢价」「事件/怀旧套利」类案例沉淀成库；**每条附 💡思考/逻辑**（信息差在哪、为什么这产品、为什么赚钱、背后逻辑、普通人可复制、事实支撑）+ M7 风险标注。信息差发现直接喂给 **M2 选品引擎** 评估成机会。
- **零积分**：案例人工精选 + 规则评分，不耗积分
- **现状**：✅ 已交付（2026-08-17，面板「🌐 中外信息差」标签，6 个真实案例；数据在 `D:\workbuddy\赚钱面板\信息差案例.json`；配套笔记 `D:\workbuddy\ObsidianVault\赚钱面板\中外信息差-套利案例库.md`）
- **优先级**：P0（信息差红利是「千万富翁视角」的核心——先发优势与套利，零成本发现）
