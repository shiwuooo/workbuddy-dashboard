# 赚钱面板 · 开源参考与可复用素材

> 调研时间：2026-08-12。目的：把市面已有的开源项目 / skills / 大佬经验，直接拿来参考、甚至白嫖，避免重复造轮子。
> 凡标注「免费」的，个人使用基本零成本；标注「需代理/付费」的，按情况取舍。

## 一、趋势雷达（M1）可直接借鉴的开源

我们现在的 M1 是**规则打分**（来源权重+新鲜度+高潜力词+信息差标，零积分）。
下面这些项目的思路可以直接增强它：

| 项目 | 性质 | 费用 | 能拿什么 | 怎么接进面板 |
|---|---|---|---|---|
| **TrendsMCP**（trendsmcp.ai / GitHub: trendsmcp） | MCP 服务器，25+ 平台实时趋势（Google/YouTube/TikTok/Reddit/X/Amazon…） | 免费额度 100 次/月 | 归一化 0–100 趋势分、跨平台增速对比（如 GLP-1 在 Google +84%、TikTok +212%） | 接 MCP 后让 AI 直接推理；我们的规则打分已覆盖其核心思路，可作为「精准增速」升级 |
| **trend-pulse**（claude-world，pip 可装） | 15 个免费源、零认证、本地历史库 | 完全免费 | **velocity（速度）+ direction（方向）打分**、关键词历史趋势 | `pip install trend-pulse`，把 velocity 维度接进 M1，补上「增速」 |
| **GitDealFlow** / **mcp-deal-flow-signal**（kindrat86） | VC 初创公司「工程加速度」先行信号 | 免费、无认证、MCP+JSON API | 「领先融资 3–6 周」的方法论：commit 增速先于官宣 | 参考「先行指标」概念，用于 M5 投资情报；数据 `/api/signals.json` 可直接抓 |

**结论**：M1 现在的规则评分已经够用（零积分）。想要「真实增速曲线」就装 trend-pulse；想要「投资先行信号」就抓 GitDealFlow 的 JSON。

## 二、执行层 / 自动化（M3 内容工厂 / M4 执行层参考）

| 项目 | 做什么 | 费用 | 参考价值 |
|---|---|---|---|
| **n8n 模板：RSS→AI改写→多平台分发** | 抓 RSS → AI 改写成 5 种社媒格式 → 发 WordPress/LinkedIn/FB/Telegram/Discord | 自托管免费 | 「发现→生成→分发」闭环的标准范本 |
| **Reddit 线索挖掘**（growwstacks + Apify） | RSS/爬虫抓高意向帖 → AI 分类 → 路由到 Telegram/CRM | Apify $45/月（可省） | 用 RSS 免费版即可做「痛点监听」 |
| **Huginn**（已在项目库） | 自建信息监控机器人，定时跑规则 | 自托管免费 | 长期挂机监控，比手动稳 |
| **MoneyPrinterV2**（已在项目库） | 海外自动化变现思路 | 开源 | 内容工厂的灵感来源 |

**结论**：M3/M4 还没做。要做「发现机会→自动生成内容→自动分发」，n8n 模板是现成脚手架；本地用免费模型或平台 API key 即可跑。

## 三、大佬信息差方法论（可直接照做，成本 $0）

这些不是工具，是**玩法**。我们的面板负责「喂信号」，下面这些负责「怎么把信号变成钱」：

1. **Reddit 研究循环**（dev.to/jackbuilds）：找痛点 → 验证需求（Google Trends 看趋势）→ 构建「人们已经要求的东西」。2 小时、$0。
2. **Reddit 产品验证 7 天 playbook**（sociavault）：痛点正则匹配（"why is there no…" / "does anyone know…"）、按 upvote+评论数排序、Day7 给 yes/no/pivot 决策。附可用 Python 代码。
3. **独立开发者社区清单**（腾讯云转载）：r/sweatystartup（线下小老板，需预约页+支付）、r/excel（野生 SaaS 源，把 Excel 流程变网页应用）、r/Parenting（C 端痛点）。**找需求要去对的地方**。
4. **海外开发者价值闭环**（tsight.io）：Reddit 信号捕捉 → GitHub 信用构建 → Product Hunt 冷启动 → Stripe 全球变现。从「出卖时间」转向「构建资产」。
5. **非公开交易 Reddit playbook**（agilegrowthlabs）：监控 1–20 万成员的中号 sub、关键词 "alternative to" / "how do I automate"、AI 线索打分、90/10 价值法则。Reddit 线索转化率是冷外的 3 倍。

**核心心法**：大佬比普通人多做的，恰恰是我们蓝图里还没建的——给信号**打分**、**自动执行**、**复盘 ROI**。M1+M6 就是补前和后的缺口。
