# 复习卡（间隔重复）

> 灵感库的"训练卡 / 决策过滤器卡"光存不够——**不复习就会忘**。这里把卡片拆成小问答，用间隔重复真正记住。
> 你申论已经用这套（obsidian-flashcards / Anki），模式一样。

## 两种用法（选一个）
1. **Obsidian + obsidian-flashcards 插件**（推荐，你已在用）
   - 装插件 → 打开本文件夹任意笔记 → 点插件"复习"按钮 → 每天刷。
   - 笔记带 `#flashcards` 标签，用 `问题 ?:: 答案` 格式，插件自动识别。
2. **Anki 桌面端**（本地免费，装到 D 盘）
   - 打开 `anki-导入.txt` → Anki 里"文件 → 导入" → 选"Basic"笔记类型 → 分隔符选"Tab" → 列1=正面，列2=背面。
   - 之后靠 Anki 的间隔重复，到期自动提醒你复习。
