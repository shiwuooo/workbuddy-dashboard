## 一、他到底强在哪

一句话：**他把"写文案"从玄学变成了工程**。

绝大多数文案教学讲的是"要有钩子、要有情绪"，埃德蒙讲的是"文案由四类模块拼装，每个模块有名字、有作用、有 KPI"。这套东西对**不会写、写得慢、写不稳定**的人杀伤力最大——因为它可复制。

## 二、招牌方法论：模块化写作思维

### 结构公式
```
一条文案 = 开篇模块 + 衔接模块 + 正文模块 + 结尾模块
        （按选题和创作意图自由组合）
```

| 模块 | 作用 / KPI | 已知打法 |
|---|---|---|
| **开篇模块** | 唯一目标：**拉高 5 秒完播率** | 5 秒撑不住，后面全白写 |
| **衔接模块** | 提升整体完播效率，防中段流失 | 常被新手完全忽略的一层 |
| **正文模块**（四大属性） | 承载内容与情绪 | **自我检讨 / 反正模块 / 罚罪复仇 / ABBA / 自我佐证** |
| **结尾模块**（四大拉数据结尾） | 拉升关注、私域、互动 | **关注模块 / 引流模块 / 互动模块** + **4 种转粉逻辑** |

### 几个具名正文模块的推测用法
> 注：模块名来自课程目录（确凿），具体讲法需听课，以下为按名称与短视频文案通行逻辑的合理推断，标注为**待听课校准**。

- **自我检讨**：先自曝踩坑/认错，降低说教感，建立可信度 → 适合知识、成长、避坑类
- **反正模块**：正反对照（错误做法 vs 正确做法），制造认知落差
- **罚罪复仇**：树立一个"共同的敌人/不公"，替观众出气 → 情绪爆点最强，易爆易翻车
- **ABBA**：先扬后抑再扬（或对称回环）结构，制造反转与呼应
- **自我佐证**：用自身经历/成果为观点背书，解决"凭什么听你的"

## 五、对我（用户）的直接用法

1. **写小红书/抖音文案时套模块**：开篇（5s）→ 衔接 → 正文模块 → 结尾（关注/引流/互动 三选一，别贪）
2. **公考资料号很适合"自我检讨 + 自我佐证"组合**：先说"我备考走过的弯路"，再用自己整理 6000+ 真题的成果背书
3. **素材库思路可直接接到现有工具链**：夸克网盘/申论素材库已有海量存量，缺的是「分类 + 检索 + 调用」——这正是他"万能素材库"讲的东西
4. **拆片法则 → 灵感库对标库**：把同赛道爆款拆成模块存进灵感库，累积成自己的模块弹药库
