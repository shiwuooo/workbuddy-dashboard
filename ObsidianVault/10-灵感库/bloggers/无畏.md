## 二、核心方法论

### 1. 用户思维反推平台算法（他的核心理念）
不去研究算法参数，而是研究**用户为什么点开、为什么收藏、为什么搜索**。用户行为对了，算法自然给量。

### 2. 老板视角 / 站在营销的高度
每条内容先问三句：**这条给我带来什么客户？值多少钱？转化路径在哪？**
只谈点赞不谈转化的内容，在他那里等于零。

### 3. 全链路打通（这是他真正的护城河）
```
账号定位 → 内容（一写就爆的文案）→ 薯条测试 → 聚光投流放大
        → 矩阵复制 → 私域引流承接 → 成交变现
```
市面上大部分老师只讲其中一段，他讲全套，且每段都有独立课程。

### 4. 投流是核心杠杆
薯条投放锦囊、聚光平台投流课、聚光代投服务。判断标准：**能被投放放大的内容，才是好内容。**

### 5. 分场景解决方案，不用一套逻辑套所有人
- 品牌商家 → 《小红书爆单锦囊课》
- 医美机构 → 《小红书医美解决方案》
- 个人博主 → 《博主训练营 3.0》《个人 IP 剪辑课》

### 6. 行业通识补充（与其打法一致，点评可引用）
> 来自小红书投放圈公开共识，非其本人原话，用作补强
- **反漏斗人群模型**：小红书特有，先打透核心人群再向兴趣人群、泛人群外扩（抖音是正漏斗，方向相反）
- **48 小时投流黄金期**：笔记发布后 48 小时是自然流量高峰，验证有效后立刻投流叠加
- **薯条 ≠ 聚光**：薯条本质是内容加热（目标只有赞藏粉），聚光才是带转化目标的效果广告
