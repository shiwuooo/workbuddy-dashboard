# 灵感库收件箱

## 用途
社媒助手（或任何工具）导出的文件丢进这个文件夹，然后对 WorkBuddy 说一句：

> 处理收件箱

WorkBuddy 会自动：
1. 读取里面的导出文件（xlsx / csv / 图片 / 视频 / md）
2. 提炼成灵感库卡片（核心观点 + 好评论摘选 + 对你的启发 + 行动建议）
3. 按用途自动打标签归类
4. 写入 `../data.js`，看板里直接可见
5. 处理完的原始文件移入 `已处理/` 子文件夹（不删除）

## 分类标签（9 类）
公考学习 / 做菜 / 旅游攻略 / 账号心得 / 运营 / 拍照参数 / 学习 / 工作 / 日常

## 命名建议（可选，不强制）
导出文件随意命名即可，WorkBuddy 会读内容判断分类。
想手动指定分类时，文件名前加类别，如：`公考_xxx评论导出.xlsx`
