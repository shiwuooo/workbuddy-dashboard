分图 ① 圣索菲亚 · 街巷分布

正门在透笼街；想接着去中央大街，从广场东出走西头道街向东 ≈0.7km（步行10分）即达中央大街南端。

分图 ② 中央大街 · 主轴 + 北端「到头后沿江怎么走」

节点走法距离/时长看点
中央大街南端(经纬街)沿主轴向北走≈1.4km / 18–20分面包石路面、欧式建筑灯、马迭尔总店
北端 = 防洪纪念塔到江边即终点—江景、纪念塔灯光
到头之后沿江走沿江南岸步道向西北（上游）走，经斯大林公园→九站公园≈1.0–1.2km / 12–15分江风、老江桥远景、公园长椅可坐；走到铁路大桥南引桥
铁路大桥上桥（步行观光桥）桥上≈0.5km桥体钢铁灯光、江两岸夜景、网红打卡

「中央大街到头」= 北端防洪纪念塔。别往回走，顺江边往上游（西北）溜达最舒服，平缓、有长椅、风凉，直接连到铁路大桥夜景，省得绕路。

分图 ③ 铁路大桥（滨洲铁路桥）· 夜景 + 接驳

铁路大桥是步行观光桥，从江南岸步道（中央大街沿江走来的方向）上南引桥即达。桥上灯光好拍，但桥面有缝、风大，老人扶栏慢走。

分图 ④ 中华巴洛克 · 整街网格 + 四大区域

区域范围看什么
A区北头道街—北四道街临江侧，老字号集中、老牌匾
B区南头道街—南四道街院落精华，张包铺胡同（排骨包子）、巴洛克浮雕最密
C区南勋街院落群大院落、砖雕门楼，适合细看
D区南平街—纯化街广场开阔广场、灯光好拍

夜游建议：从B区张包铺胡同进 → 沿靖宇街向东慢走看灯光 → 拐 C区院落 → 收尾 D区广场。巷子是老石板/修补路面，不平，穿平底防滑鞋。
