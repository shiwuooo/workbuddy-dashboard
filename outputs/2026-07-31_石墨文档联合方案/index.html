2026-07-31 · 小白可执行版 · 信息来源：石墨开放平台文档 + 海外 AI×文档工作流实践

一句话结论

石墨强在「人写、人协作」，WorkBuddy 强在「AI 处理、生成、自动化」。两者联合的本质是：让 WorkBuddy 直接吃进石墨内容 → 出结果 → 回流石墨。

难点不在 AI，而在石墨把内容交出来的通道。石墨公网个人版几乎没有开放接口，这是所有方案的分水岭。

③ 海外成熟范式借鉴（让联合更聪明）

Notion AI 数据库 + AI 属性 + 自动化：先设计好库结构（状态/分类字段），AI 按字段自动生成大纲、摘要、推广文案。映射做法：用石墨应用表格当数据库，WorkBuddy 当 AI 引擎，按状态字段触发处理。

OpenKnowledge（开源 GPL-3.0） 原生 MCP，AI 与人对同一份文档实时共编，消灭「复制→粘贴→改→再粘贴」的往返损耗。这是「强强联合」的理想范式，值得等官方 Skill 时对标。

Google Docs + Zapier + ChatGPT 文件夹即触发器：文档进指定文件夹 → AI 摘要/改写 → 写回 Docs 并通知。零代码自动化思路，可直接套到「方案 A」做成半自动。

④ 我的推荐路径

个人免费版用户：先走 方案 A 立刻受益；同时把常需 AI 处理的文档设为「互联网公开发布」，让 WorkBuddy 用 WebFetch 直接读，省去复制粘贴。

想彻底省心、能迁移：走 方案 D —— 腾讯文档（个人/企业版 Skill 已内置）、飞书（lark-doc/sheets/base 已连）WorkBuddy 均已深度支持，开箱双向。

企业团队：走 方案 E（开放平台）或 方案 B（私有部署 token + MCP）。

长期最省心：等 方案 C 官方石墨 Skill 上线。

关键提醒

  • 石墨公网个人版没有开放 API，凡标「一键同步石墨」的第三方多半违规或泄露风险，勿轻信。
  • 「互联网公开发布」仅用于可公开内容，敏感/私密文档切勿公开。
  • 企业 API 需资质 + 付费，且要自建回调后端，个人用户性价比低。
  • WorkBuddy 当前已原生支持 MCP（~/.workbuddy/mcp.json），未来官方石墨 Skill 或合规 MCP 可直接接入。
