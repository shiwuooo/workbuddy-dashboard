# 知乎内容整理利用工作台 · 使用说明

## 是什么
一个**纯本地、零上传**的知乎高赞内容整理工作台。把刷到的知乎问题，拆成：
原标题 / 链接 / 问题 / 答案 / 高赞答案 / 答案间的想法·思路·技巧·实操 / 相同内容去重（观点聚类）/ 进一步扩展（多维度利用）。

## 文件
- `index.html` —— 工作台界面（双击打开即可，无需联网、无需安装）。
- `data.js` —— 数据层（所有内容结构化在此，纯本地）。
- `使用说明.md` —— 本文件。

## 怎么用
1. 双击 `index.html`（用 Chrome / Edge / Firefox 均可）。
2. 左侧导航：**总览** → 看统计与问题卡片墙；点问题 → 看详情；**跨问题去重** → 看多个问题的共识与矛盾。
3. 详情页分区：答案、洞察区（思路/技巧/实操/套路/坑/金句）、观点聚类（去重）、扩展区（选题/话术/案例/方法论/分发/SOP/产品化）。

## 怎么加新问题（交给 AI 做，你不用动手）
把知乎问题链接发给我，我会：
1. 抓取正文 → 2. 结构化成一条数据 → 3. 追加进 `data.js` 的 `questions` 数组 → 4. 你刷新 `index.html` 即可见。
> 你也可以在 `data.js` 里手动照葫芦画瓢加一项，字段含义见下方。

## data.js 字段速查
```
questions: [{
  id, title, url, questionDesc, answerCount, topAnswerCount,
  answers: [{ author, votes(null=未获取), role, summary, highlights:[...] }],
  topAnswers: ["q1-a0"],           // 高亮答案标记
  insights: [{ type, text, from }], // type: 思路/技巧/实操/套路/坑/金句
  clusters: [{ theme, mergedFrom, points }], // 同问题内去重
  expansions: [{ angle, draft }]    // angle: 选题/话术/案例/方法论/分发/SOP/产品化
}]
crossClusters: [{ theme, inQuestions, points, tension? }] // 跨问题去重
```
